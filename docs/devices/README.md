# Find your model

The guides describe the versions tested in October 2026. Match the platform and
hardware revision as well as the model name; similar names can need different firmware.

| Model | What you can learn | Tested firmware |
|---|---|---|
| [DS-KD8003-IME1](ds-kd8003-ime1.md) | Root shell, hardware pinout, audio APIs | V2.2.62 build 230204, original non-B hardware |
| [DS-2CD2T87G2-L](ds-2cd2t87g2-l.md) | G3 hardware, root access, managed upgrade, AI interfaces | V5.5.154 build 200928 → V5.5.820 build 231108, original non-C hardware |
| [DS-2CD2386G2-ISU/SL](ds-2cd2386g2-isu-sl.md) | G5 firmware decoding, root access and upgrade persistence | V5.5.113 → V5.7.23 build 260320, C variant |
| [DS-KH9510-WTE1](ds-kh9510-wte1.md) | Android panel platform notes | V2.2.28 build 230613 |

For G3/G5 access, read [root and persistent SSH](../security/owner-access.md).

and [AI hardware notes](../software/local-compute.md).
